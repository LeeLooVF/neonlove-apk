# NeonLove Live - Projet Android Natif (APK automatique via GitHub Actions)

## Comment obtenir ton fichier `.apk` en 3 clics sur GitHub :
1. Crée un nouveau dépôt sur ton compte **GitHub** (ex: `neonlove-apk`).
2. Décompresse ce fichier `.zip` et envoie tous les fichiers (y compris le dossier `.github`) sur ton dépôt GitHub.
3. Clique sur l'onglet **Actions** de ton dépôt GitHub : le workflow **Build NeonLove Live APK** se lance tout seul et génère le fichier **`NeonLoveLive-APK.zip`** contenant `app-debug.apk` prêt à installer sur ton téléphone et celui de Lydie !
